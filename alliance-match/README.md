# 同盟 3人組マッチング (alliance-match)

ゲームの **投票メンバー画面のスクリーンショット** をアップロードすると、名前・戦力(グーパンチ横の数値)・開催日時を読み取り、
戦力の高いメンバーを各組に1人ずつ配置した **3人組** を自動で編成して、メンバー向けの **お知らせ文** を作る Web アプリです。

- サーバー不要の静的サイト(GitHub Pages で公開できます)
- 文字認識(OCR)は [Tesseract.js](https://github.com/naptha/tesseract.js) でブラウザ内で実行。画像は外部に送信されません
- 管理者が結果をコピーして、同盟チャットやメールにそのまま貼り付けられます

## 使い方

1. **投票メンバー画面のスクショを選ぶ**  
   名前、戦力、開催日時を読み取ります。人数が多いときはスクロールして複数枚まとめて選べます(同じ人は1回だけ数えます)。
2. **読み取り結果を確認する**  
   化けた名前や戦力は表で直せます。参加しない人は ✕ で外せます。
3. **組分けを作る**  
   戦力の高い順に並べ、**スネーク方式**で配って各組に上位者を1人ずつ置き、リーダーを固定したまま合計戦力のばらつきを最小化します。
   余りは「人数の少ない組を作る(2人組)」か「既存の組に加える(4人組)」を選べます。
4. **お知らせ文をコピーする**  
   イベント名・開催日時・本部リーダー(いちばん戦力の高い人。変更可)を差し込んだお知らせ文ができます。
   文面のひな形は編集でき、この端末に記憶されます。「戦力も載せる」で各組の戦力と合計を添えられます。

既定のお知らせ文:

```
【クレイジージョイ】チーム発表
みなさん、投票ありがとうございました！
次回の開催は9/24(木)22:30からです。
事前準備のため、10分前にはオンラインになってもらえると助かります。

今回の3人組の組み合わせが決まったので、お知らせします。

【1組】nnnnnnn ・ てとてと ・ Hunter
【2組】ayataka3 ・ アスカーニャ ・ un temps libre
【3組】むにお ・ ふくにゃんBLv
【4組】黒豆禿げ茶 ・ chucky

◾️本部リーダー　nnnnnnn

不明点があれば 同盟チャットで確認してください。
よろしくお願いします！
```

### 開催日時の読み取り

スクショ全体から `9/24(木) 22:30`、`9月24日 22:30`、`09/24 22時30分` のような表記を探します(曜日が無ければ日付から補います)。
見つからなかったときは「開催日時」欄に手で入力してください。

## 公開方法(GitHub Pages)

1. このリポジトリを GitHub に push します。
2. リポジトリの **Settings → Pages** で Source を `Deploy from a branch`、Branch を `main` / `/ (root)` にして保存。
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/alliance-match/` で開けます。

初回アクセス時は Tesseract.js 本体と日本語・英語の言語データ(合計 10MB 弱)を jsDelivr CDN から取得します。
2回目以降はブラウザにキャッシュされます。

## 読み取りのコツ

- スクショは端末のスクリーンショット機能で撮った元サイズのまま使ってください(圧縮・トリミングすると精度が落ちます)。
- 画面の下で切れているカードは無視されます。
- 日本語の名前は読み違いが出ることがあります。信頼度の低い行は黄色で表示されるので、表で直してからお知らせ文を作ってください。

## 開発

```bash
cd alliance-match
npm test                       # 編成・日時解釈・お知らせ文の単体テスト(Node 20+)
npm run vendor                 # オフライン/ローカルテスト用に Tesseract 資材を ./vendor へ配置
npm run serve                  # http://127.0.0.1:8765 で配信(?ocr=local を付けると vendor を使用)
npm i && FIXTURES=/path/to/shots npm run e2e   # Chromium でスクショを流す実機テスト
```

構成:

- `index.html`, `css/style.css` … 画面
- `js/ocr.js` … カードの検出、前処理、Tesseract 呼び出し、開催日時の検出
- `js/matching.js` … 戦力の解釈、組分け、日時の解釈、お知らせ文の生成(純粋関数)
- `js/app.js` … 画面制御
