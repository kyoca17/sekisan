# 同盟 3人組マッチング (alliance-match)

ゲームの **投票メンバー画面のスクリーンショット** をアップロードすると、名前と戦力を読み取り、
戦力の高いメンバーを各組に1人ずつ配置した **3人組** を自動で編成する Web アプリです。

- サーバー不要の静的サイト(GitHub Pages で公開できます)
- 文字認識(OCR)は [Tesseract.js](https://github.com/naptha/tesseract.js) でブラウザ内で実行。画像は外部に送信されません
- **戦力マスター** は「同盟ランキング(総力)」画面のスクショで随時メンテナンスできます

## 使い方

1. **戦力マスターを整える**  
   「戦力マスター」タブで、同盟ランキング(総力)をスクロールしながら撮ったスクショをまとめて選択します。
   読み取り結果(更新/新規)を確認して「マスターに反映」。
2. **投票メンバーを読み取る**  
   「マッチング」タブで投票メンバー画面のスクショを選択します。名前と戦力を読み取り、マスターと照合します。
   名前が読み違えられても、戦力(0.1M単位)が一致する人が1人だけなら自動で同一人物とみなします(要確認の色で表示)。
3. **組分けを作る**  
   「組分けを作成」で3人組ができます。「結果をコピー」でチャットに貼り付けられます。

### 組分けのルール

- 戦力の高い順に並べ、**スネーク方式**(1→g, g→1, 1→g …)で配ります。各組に上位者が1人ずつ入ります。
- 各組の先頭(リーダー)は固定したまま、残りのメンバーの入れ替えで **合計戦力のばらつきを最小化** します(オプションで無効化可)。
- 余りが出る場合は「人数の少ない組を作る(2人組)」か「既存の組に加える(4人組)」を選べます。

## 公開方法(GitHub Pages)

1. このリポジトリを GitHub に push します。
2. リポジトリの **Settings → Pages** で Source を `Deploy from a branch`、Branch を `main` / `/ (root)` にして保存。
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/alliance-match/` で開けます。

初回アクセス時は Tesseract.js 本体と日本語・英語の言語データ(合計 10MB 弱)を jsDelivr CDN から取得します。
2回目以降はブラウザにキャッシュされます。

### 戦力マスターの共有

マスターは各ブラウザの `localStorage` に保存されます。別の端末やメンバーと共有するときは
「JSONを書き出す」で保存した内容を `data/power_master.json` としてコミットしてください。
localStorage が空の端末(初回アクセス)では、このファイルが初期データとして読み込まれます。
「同梱データで初期化」ボタンでいつでも読み直せます。

## 対応している画面

| 画面 | 読み取るもの | 備考 |
| --- | --- | --- |
| 投票メンバー | 名前、戦力(例 `38.8M`) | 2列カード。画面下で切れているカードは無視されます |
| 同盟ランキング(総力) | 名前、戦力(例 `38,870,574`) | 途中で切れている行は無視。複数枚の重複は自動で除去 |

スクショは端末のスクリーンショット機能で撮った元サイズのまま使ってください。

## 開発

```bash
cd alliance-match
npm test                       # 照合・編成ロジックの単体テスト(Node 20+)
npm run vendor                 # オフライン/ローカルテスト用に Tesseract 資材を ./vendor へ配置
npm run serve                  # http://127.0.0.1:8765 で配信(?ocr=local を付けると vendor を使用)
npm i && FIXTURES=/path/to/shots npm run e2e   # Chromium でスクショを流す実機テスト
```

構成:

- `index.html`, `css/style.css` … 画面
- `js/ocr.js` … カード/行の検出、前処理、Tesseract 呼び出し
- `js/matching.js` … 名前の正規化・類似度、マスター照合、組分け(純粋関数)
- `js/store.js` … マスターの保存/読込/JSON入出力
- `js/app.js` … 画面制御
- `data/power_master.json` … 初期マスター
